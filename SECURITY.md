## Reporting a Vulnerability

The RizkybyMONITOR team takes the security of our application and our users seriously.

If you believe you have discovered a security vulnerability (such as a local privilege escalation or injection issue):

1. **Do NOT report security vulnerabilities through public GitHub issues.**
2. Please report the issue privately through [GitHub Private Vulnerability Reporting](https://github.com/rizkybayuu/RizkybyMONITOR/security/advisories/new) or contact the maintainer directly.
3. Include detailed steps to reproduce the vulnerability, along with proof-of-concept code or terminal outputs if available.
4. We will acknowledge receipt of your report within 48 hours and coordinate a fix and advisory.
